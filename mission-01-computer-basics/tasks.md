## Task 1.1 - Trace One Activity Using IPOS
IPOS stands for Input, Processing, Output, and Storage. It describes how a computer receives information, works with it, produces a result, and saves information for later use.

| Stage | What happens in my example? | Hardware or component |
|---|---|---|
| Input | I press keys to enter text | Keyboard |
| Processing | The computer interprets the keystrokes and displays the text in the document app | Processor and memory |
| Output | I see the text on the screen | Display |
| Storage | I save the document so I can open it later | SSD |

## Task 1.2 - Identify Harsdware And Software
Hardware means the physical parts of a computer that I can touch. Software means the programs and instructions that run on the computer. Software can be an operating system, an application, or a utility.
| Item | Hardware or software | Software type, if applicable | Purpose |
|---|---|---|---|
| Keyboard | Hardware | — | Enters text and commands |
| Display | Hardware | — | Shows text, images, and video |
| macOS | Software | Operating system | Manages the computer and its resources |
| Web browser | Software | Application | Opens and displays websites |
| Mouse or trackpad	| Hardware | — | Moves the pointer and selects items |
| SSD or storage drive | Hardware | — | Stores files and applications |
| Text editor |	Software | Application | Creates and edits text files |
|Backup or security tool | Software | Utility |	Helps protect or maintain the computer |

## Task 1.3 - Computer Systems Around You
A computer system takes input, processes information, and produces an output to perform a specific job. These systems can be part of everyday devices, not just laptops or phones.

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Provides banking services | Card and PIN | Cash or account information |
| Traffic signal | Controls traffic flow | Vehicle or pedestrian sensor | Traffic lights |
| Ticket machine | Sells or prints tickets | Ticket choice and payment | Printed ticket |
