# Mission 3 — Understand the Operating System

## 1. Task / objective

Explore the operating system, running processes, storage, file paths, and permissions. Explain the main responsibilities of an operating system.

## 2. Work completed

I checked the macOS version, looked at storage information, and observed a short snapshot of running processes. I compared absolute and relative paths, inspected file permissions, and described common operating-system responsibilities.

## 3. Commands / tools used

- `sw_vers` — displayed macOS version information.
- `df -h` — displayed storage usage and available space.
- `ps -ax | head -n 10` — displayed the first ten lines of a process list.
- `pwd` — displayed the current directory.
- `cd mission-03-operating-system` — moved into the Mission 3 folder.
- `ls -l README.md` — displayed details and permissions for the README file.

## 4. My understanding

An operating system manages the computer’s hardware and provides services that applications use. A process is a program or service that is currently running. A path identifies a file or folder. File permissions control whether users can read, write, or execute a file.

## 5. Difficulties faced

## 6. How I resolved them
