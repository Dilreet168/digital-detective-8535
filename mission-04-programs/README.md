## 4. My understanding
A compiler usually translates source code before the program runs, often producing another file such as an executable. An interpreter usually reads and executes code while the program runs. Compiled programs can run efficiently after translation, while interpreted code can be convenient to test. Some languages use a combination of both approaches.
