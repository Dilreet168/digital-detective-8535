# Mission 4 - How Programs Run

## Task 4.2 — Compare a compiler and an interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation or execution happens | Usually translates the source code before the program runs. | Usually reads and executes the program while it runs. |
| Typical output | Often produces a separate executable or translated file. | Usually runs the code through the interpreter without producing a separate executable for the user. |
| One example | A C compiler translates C source code. | Python is commonly run through an interpreter such as CPython. |
| One advantage | The translated program can run efficiently after compilation. | It is convenient for testing and running code quickly. |

A compiler usually translates source code before running the program, while an interpreter executes code as the program runs. A compiler often creates a separate output file, whereas an interpreter commonly runs the code through its runtime. Each approach has advantages, and some languages use a combination of both.
